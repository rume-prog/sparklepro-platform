# SparklePro Cleaning Services Booking and Operations Platform

## Overview

A professional website and booking platform for a cleaning services business. Currently in the planning stage.

## Problem Solved

Small cleaning businesses often lack a professional online presence, making it difficult for customers to find reliable information, understand services, and contact the company. This platform provides a trustworthy website that can scale into a full booking management system.

## Features

### Phase 1 (Planned)
- Multi-page site with Home, Services, About, and Contact pages
- React Router for navigation
- Booking form that opens a pre-filled WhatsApp message
- Responsive design for desktop and mobile
- Plain CSS with CSS variables

### Phase 2 (Planned)
- Node.js/Express backend
- PostgreSQL database for booking storage
- Admin login and dashboard
- Booking management system

## Tech Stack

- **Frontend**: React + Vite, JavaScript, plain CSS with CSS variables
- **Testing**: Vitest and React Testing Library
- **Backend (Phase 2)**: Node.js/Express, PostgreSQL
- **Deployment**: Netlify

## Prerequisites

- Node.js (version 18 or higher)
- npm (comes with Node.js)
- Git
- Modern web browser
- Code editor
