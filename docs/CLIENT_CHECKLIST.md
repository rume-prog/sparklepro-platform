# Client Checklist

To deploy a new client site, collect the following information from the client:

## Business Information
- [ ] Business name
- [ ] Tagline or slogan
- [ ] Brief business description (1-2 sentences)
- [ ] Business story/history for About page
- [ ] Mission statement
- [ ] Customer count (if applicable)

## Services and Pricing
- [ ] List of services offered
- [ ] Description for each service
- [ ] Starting price for each service (or price range)
- [ ] Any specialized services offered

## Contact Details
- [ ] Phone number
- [ ] Email address
- [ ] Physical address
- [ ] City/location
- [ ] Business hours (Monday-Friday, Saturday, Sunday)
- [ ] WhatsApp number (if different from main phone)
- [ ] Typical response time for inquiries

## Branding Assets
- [ ] Logo file (PNG, SVG, or similar)
- [ ] Brand colors (if different from default theme)
- [ ] Business photos (for gallery, if enabled)

## Technical Requirements
- [ ] Domain name ownership confirmation
- [ ] Hosting account details (if not using default)
- [ ] SSL certificate (if not auto-provisioned)

## Content Preferences
- [ ] Value propositions (Why Choose Us section)
- [ ] Company values (for About page)
- [ ] Customer satisfaction policy
- [ ] Type of cleaning products used (eco-friendly, commercial-grade, etc.)

## Feature Selection
Confirm which features to enable in `src/config/site.js`:
- [ ] Booking form (bookingForm: true/false)
- [ ] Photo gallery (gallery: true/false)
- [ ] Pricing table (pricingTable: true/false)

## Notes
- All placeholders marked with `[BRACKETS]` in the config must be replaced
- Review `src/config/site.js` for all configuration options
- Test the site locally before deployment
